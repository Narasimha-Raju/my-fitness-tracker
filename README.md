# Personal Fitness Tracker

Open `index.html` to use the tracker.

## Persistence
Daily records are stored in the browser using `localStorage`, keyed by date. Re-opening the pages does not reset previous dates on the same browser/device.

## Files
- `index.html` – home
- `diet-tracker.html` – nutrition tracker
- `workout-tracker.html` – workout tracker
- `references/` – uploaded routine images

## Important
Because this is a static site, browser storage is local to the browser/device. It is not a cloud database and does not automatically sync between devices/browsers.
